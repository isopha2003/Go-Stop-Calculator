# GO-Stop-Calculator
> 가정에서 간단하게 사용할 수 있는 고스톱 점수 계산 및 정산 프로그램

## 사용 기술
- **Language**: Java
- **Tool**: Eclipse

## 주요 기능
1. **점수 계산**: 사용자가 기본 점수 입력 후 해당 사항에 체크 시 자동적인 점수 계산
2. **자동 정산**: 참가자에 따라 지불해야 할 금액 화면에 정리

## 핵심 경험
### 1. 일상생활에서의 코딩 활용
- 일상생활에서 겪은 불편함을 간단한 프로그램 코딩을 통해 해결할 수 있었음. 이러한 경험을 통해 지금까지 겪었던 문제들을 그냥 넘어가지 않고 "어떻게 하면 코딩을 통해서 해결할 수 있을까?" 하는 사고를 가지게 됨.
